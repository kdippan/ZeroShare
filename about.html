The idea

What is ZeroShare?

ZeroShare is a privacy-focused file transfer application created to make moving files between devices simple, direct and browser-native.

Instead of treating every transfer as a cloud upload, ZeroShare uses WebRTC to establish a connection between participating browsers. Once connected, the browsers can exchange file data through a WebRTC DataChannel.

Browser-first

No dedicated desktop application required.

Peer-to-peer

File data is exchanged through WebRTC.

Encrypted

Transfer data uses modern browser cryptography.

Network infrastructure

TURN infrastructure

Current allowance

500 MB monthly TURN trial allowance

ZeroShare currently uses Metered TURN infrastructure to help establish WebRTC connections when direct peer-to-peer connectivity is unavailable.

The current Metered trial provides a 500 MB monthly allowance for TURN relay traffic. TURN is not required for every connection. When browsers can establish a direct WebRTC path, relay infrastructure may not be required.

Because ZeroShare is currently operating with a limited trial allowance, TURN-dependent connections may be affected if the available allowance is exhausted during a billing cycle.

Common questions

Frequently asked questions

What is ZeroShare?

ZeroShare is a browser-based peer-to-peer file-sharing application designed to transfer files between connected browsers using WebRTC.

Does ZeroShare use cloud file storage?

ZeroShare is designed around direct WebRTC data transfer rather than a conventional cloud-storage upload and download workflow.

What encryption does ZeroShare use?

ZeroShare uses ECDH P-256 for key exchange and AES-256-GCM for encrypted transfer data through browser-native cryptographic capabilities.

What happens when direct WebRTC connectivity is unavailable?

WebRTC can use network traversal infrastructure such as TURN to relay traffic when a direct peer-to-peer path cannot be established.

What is the current TURN allowance?

ZeroShare currently has a 500 MB monthly Metered TURN trial allowance. TURN relay usage is only relevant to connections that require relay infrastructure.
