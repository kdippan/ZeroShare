What is ZeroShare?

ZeroShare is a browser-based peer-to-peer file transfer application focused on private communication between devices. Instead of following a conventional cloud upload and download model, the application establishes a WebRTC connection between participating browsers.

File data is encrypted locally before it is transferred. This architecture is intended to keep the original file contents out of conventional server-side file storage.

WebRTC attempts to establish a suitable network path. STUN can assist with NAT discovery, while TURN can relay encrypted transport traffic when a direct peer connection cannot be established. TURN is not equivalent to conventional file storage.

Privacy by Design

Client-Side Encryption

File data is encrypted in the browser before encrypted application data is sent through the WebRTC connection.

Peer-to-Peer Architecture

The application is designed around browser-to-browser communication instead of conventional cloud file storage.

ECDH

Browsers use Elliptic Curve Diffie-Hellman key agreement to derive shared cryptographic material.

AES-256-GCM

Authenticated encryption protects application-level file data before transport.

Transfer Process

1

Connect the browsers

Signaling and WebRTC ICE negotiation establish a communication path between the participating browsers.

2

Establish cryptographic material

The browsers exchange public key material and derive shared key material using ECDH.

3

Encrypt locally

File data is processed into chunks and encrypted with AES-256-GCM inside the sender browser.

4

Transfer encrypted data

The encrypted chunks travel through the WebRTC DataChannel.

5

Decrypt locally

The receiving browser authenticates and decrypts the encrypted chunks locally and reconstructs the file.

Current infrastructure

TURN Infrastructure

ZeroShare currently uses Metered TURN infrastructure for WebRTC network traversal.

Current free allowance 500 MB TURN usage

At the moment, ZeroShare is running on Metered's free 500 MB monthly TURN allowance. Metered calculates TURN usage from transferred ingress and egress traffic.

TURN is only needed for connections that require relay infrastructure. When the available allowance is exhausted, some users may be unable to establish connections that depend on TURN until the allowance becomes available again or the infrastructure plan is upgraded.

As ZeroShare grows, infrastructure usage will also grow. Keeping the service available therefore requires ongoing hosting, networking and TURN infrastructure costs.

Understanding the Network

Peer-to-peer does not guarantee that every connection can always be established directly. NAT, firewalls and network policies can prevent browsers from communicating through a direct route.

STUN can help browsers discover their public network mapping. If a direct connection cannot be established, TURN can relay the WebRTC transport traffic.

Application-level file contents are encrypted before they enter the WebRTC data channel. Signaling and network infrastructure can nevertheless process connection-related metadata required to establish the session.

Frequently Asked Questions

What is ZeroShare?

ZeroShare is a browser-based peer-to-peer file transfer application designed for private and encrypted file sharing between devices.

How does ZeroShare protect file contents?

File data is encrypted in the browser using AES-256-GCM before encrypted application data is transmitted through the WebRTC data channel.

Does ZeroShare use TURN servers?

WebRTC can use STUN and TURN infrastructure depending on network conditions. ZeroShare currently uses Metered TURN infrastructure for network traversal.

What happens if the TURN allowance is exhausted?

Connections that require TURN relay infrastructure may stop working until additional allowance is available or the infrastructure plan is upgraded. Direct WebRTC connections are not inherently dependent on TURN.

Can ZeroShare transfer large files?

ZeroShare is designed to support large file transfers, subject to browser resources, device capabilities and network conditions.

Why can I donate to ZeroShare?

Donations help support the infrastructure required to operate and maintain the project, including hosting, networking and TURN relay services.
